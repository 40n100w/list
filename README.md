# Pi-hole blocklists

Copy the link for each list you want into Pi-hole’s **Lists** page, choose **Add blocklist**, then update Gravity.

| List | What it targets |
| --- | --- |
| [ads.txt](https://raw.githubusercontent.com/40n100w/list/main/ads.txt) | Hosts used to auction and deliver ads on websites and in apps. Sponsored posts served from the same host as a social feed can still appear. |
| [trackers.txt](https://raw.githubusercontent.com/40n100w/list/main/trackers.txt) | Third-party services that measure visits, collect interaction events, or record browsing sessions. |
| [telemetry.txt](https://raw.githubusercontent.com/40n100w/list/main/telemetry.txt) | Optional blocking for services that receive app usage statistics, diagnostics, and crash reports. |
